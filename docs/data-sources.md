# 학습 데이터 출처 원장

이 문서는 게임에 들어간 학습 데이터가 **어디서 왔고 무엇으로 검증되는지**를 적는다.
게이트 = `node tools/check-data.mjs` (D23, 릴리스 차단). 개수 선언이 실제 데이터와 어긋나면 실패한다.

## 1. 구구단 — 72개 문항 (`src/core/questions.js` 생성)
- 범위: 2단~9단 × 1~9. 곱셈구구는 **수학적 사실**이라 저작권 대상이 아니다.
- 검증: 값 전수 재계산(`tools/check-data.mjs` §①). 사람이 옮겨 적은 곱셈표가 없다 — 코드가 계산한다.
- 교과 연계: 2022 개정 교육과정 수학 2학년 「곱셈구구」.

## 2. 흔한 오류 사전 (`src/data/gugudan-common-errors.js`, 25키)
- 성격: 아이들이 실제로 자주 혼동하는 값(인접 단 혼동 7×8↔6×9, 자리 반전 63↔36, 한 칸 밀림).
- 출처: 제작진이 초등 수업 현장 경험을 바탕으로 편성한 목록이며, 특정 교재를 옮긴 것이 아니다.
- 검증: 정답과 다른 자연수인가, 정답에서 지나치게 멀지 않은가를 기계가 본다.
- ⚠️ 이 목록은 «자주 틀리는 값»에 대한 제작진의 판단이다. 교육 연구 문헌으로 뒷받침된 통계가 아니다.

## 3. 영단어 — words-g34 160개 / words-g56 160개
- 성격: **제작진이 자체 편성한 초등 기본 어휘 목록**이다. 뜻·품사도 직접 작성했다.
- 🔴 명확히 해 둘 것: 교육부 고시 어휘표를 그대로 옮긴 목록이 **아니다**. 초등 3~6학년 수준의
  일반적인 기본 어휘(동물·색·수·가족·학교·음식·몸·자연·동사·형용사·생활)를 범주별로 편성했다.
  공식 고시 어휘표와의 1:1 대조는 **사용자 확인 항목**으로 남아 있다(GDD D23 참조).
- 교과서·시판 단어장의 예문·배열을 복제하지 않았다. 예문은 게임에 넣지 않았다(뜻만 쓴다).
- 검증(기계): 개수 160, 밴드 내·밴드 간 단어 중복 0, 같은 뜻이 두 단어에 붙지 않음,
  품사 값이 {n, v, a, num} 안, 품사별 최소 3개(같은 품사 오답 2개를 만들 수 있어야 한다).
- 검증(사람): 철자·뜻·품사는 배포 전 교차검증 1회를 거친다.

## 4. 남은 사용자 확인 항목
1. 교육부 고시 초등 권장 어휘표와의 대조(포함 여부·학년 배정)
2. 흔한 오류 사전을 실제 학급 오답 데이터로 보정
