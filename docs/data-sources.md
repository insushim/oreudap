# 학습 데이터 출처 원장

이 문서는 게임에 들어간 학습 데이터가 **어디서 왔고 무엇으로 검증되는지**를 적는다.
게이트 = `node tools/check-data.mjs` (D23, 릴리스 차단). 개수 선언이 실제 데이터와 어긋나면 실패한다.

## 1. 구구단 — 72개 문항 (`src/core/questions.js` 생성)
- 범위: 2단~9단 × 1~9. 곱셈구구는 **수학적 사실**이라 저작권 대상이 아니다.
- 검증: 값 전수 재계산(`tools/check-data.mjs` §①). 사람이 옮겨 적은 곱셈표가 없다 — 코드가 계산한다.
- 교과 연계: 2022 개정 교육과정 수학 2학년 「곱셈구구」.

## 2. 흔한 오류 사전 (`src/data/gugudan-common-errors.js`, 25키)
- 성격: 아이들이 실제로 자주 혼동하는 값(인접 단 혼동 7×8↔6×9, 자리 반전 63↔36, 한 칸 밀림).
- 출처: 제작진이 초등 수업 현장 경험을 바탕으로 편성한 목록이며, 특정 교재를 옮긴 것이 아니다.
- 검증: 정답과 다른 자연수인가, 정답에서 지나치게 멀지 않은가를 기계가 본다.
- ⚠️ 이 목록은 «자주 틀리는 값»에 대한 제작진의 판단이다. 교육 연구 문헌으로 뒷받침된 통계가 아니다.

## 3. 영단어 — words-g34 617개 / words-g56 590개
- 성격: **제작진이 자체 편성한 초등 기본 어휘 목록**이다. 뜻은 직접 작성했고, 품사는 표기 규칙으로 자동 부여했다.
- 생성물이다 — `npm run words:import` 가 만든다. 손으로 고치면 다음 실행에 지워진다.
- 🔴 명확히 해 둘 것: 교육부 고시 어휘표를 그대로 옮긴 목록이 **아니다**. 초등 3~6학년 수준의
  일반적인 기본 어휘(동물·색·수·가족·학교·음식·몸·자연·동사·형용사·생활)를 범주별로 편성했다.
  공식 고시 어휘표와의 1:1 대조는 **사용자 확인 항목**으로 남아 있다(GDD D23 참조).
- 교과서·시판 단어장의 예문·배열을 복제하지 않았다. 예문은 게임에 넣지 않았다(뜻만 쓴다).
- 검증(기계): 개수는 원장 선언과 1:1 대조(밴드당 500개 이상), 밴드 내·밴드 간 단어 중복 0, 같은 뜻이 두 단어에 붙지 않음,
  품사 값이 {n, v, a, num} 안, 품사별 최소 3개(같은 품사 오답 2개를 만들 수 있어야 한다).
- 검증(사람): 철자·뜻·품사는 배포 전 교차검증 1회를 거친다.

## 4. 국어 어휘 — korean-g34 256개 / korean-g56 250개

- 성격: **AI 웹 브릿지(gpt-web·gemini-web)가 생성한 목록을 기계가 전수 검증해 추린 것**이다.
  생성물이므로 손으로 고치지 말고 `npm run korean:import -- <원본디렉터리>` 를 다시 돌린다.
- 🔴 명확히 해 둘 것: 교육부 고시 어휘표나 특정 교과서를 옮긴 목록이 **아니다.**
  초등 3~6학년 수준의 주제(마음·감정, 자연·날씨, 학교생활, 음식·맛, 몸·건강, 사물·도구,
  생각·판단, 사회·공동체, 말과 글, 과학·자연 현상, 성품·태도, 시간·변화)별로 받아 편성했다.
  공식 어휘표와의 1:1 대조는 **사용자 확인 항목**으로 남아 있다(§5).
- 뜻풀이는 사전 정의를 옮긴 것이 아니라 **아이가 읽을 수 있게 줄인 풀이**다. 사전 문장을 복제하지 않았다.
- 🔴 **뜻풀이 8자 상한은 화면이 정한 값**이다(취향이 아니다). 3갈래 칸 폭 105px(360px 화면)에서
  글자 18px 하한을 지키며 두 줄에 들어가는 한글이 8자까지고, 9자부터 세 줄이 되어 글자 상자가
  발판을 덮는다. 상한을 늘리려면 데이터가 아니라 레이아웃을 먼저 바꿔야 한다(D43 · `CHOICE_FIT`).
- 검증(기계 · `tools/check-data.mjs` §③-2 + `tools/import-korean.mjs`):
  개수는 원장 선언과 1:1 대조(밴드당 200개 이상) / 낱말은 한글 2~5자 / 뜻은 2~8자 /
  **뜻을 붙여 쓰지 않았는가**(6자 이상인데 띄어쓰기가 없으면 아이가 못 읽고, `word-break: keep-all`
  이 줄바꿀 자리를 못 찾아 낱말 «안»에서 잘린다) / **뜻에 낱말이 들어 있지 않은가**(있으면 답이 보인다) /
  밴드 내·밴드 간 낱말 중복 0 / **뜻이 서로를 포함하지 않는가**(한 문제의 두 보기가 되면 정답이 둘이 된다) /
  품사 값이 {n, v, a, ad} 안 / 품사별 최소 3개 / 난이도 t 가 1~3.
- 받은 것을 그대로 쓰지 않았다 — 위 규칙으로 **964건을 버리고** 506개를 채택했다.
- 검증(사람): 뜻·난이도 배정은 배포 전 교차검증 1회를 거친다. **아직 하지 않았다면 §5 에 남는다.**

## 5. 남은 사용자 확인 항목
1. 교육부 고시 초등 권장 어휘표와의 대조(포함 여부·학년 배정) — 영단어·국어 어휘 둘 다
2. 국어 어휘 뜻풀이의 사람 검수(뜻이 맞는가·학년에 맞는가). 기계는 «모양»만 봤지 «옳은가»는 못 본다
2. 흔한 오류 사전을 실제 학급 오답 데이터로 보정
