## 3. 저작권·상표·부정경쟁 리스크 체크 (상업 배포 전제)
근거 확인 출처:
- 무한의 계단 = NFLY STUDIO, 2015-01-16 출시, 하단 2버튼(오르기 / 방향전환) 구조 — [나무위키](https://namu.wiki/w/%EB%AC%B4%ED%95%9C%EC%9D%98%20%EA%B3%84%EB%8B%A8)
- **대법원 2019. 6. 27. 선고 2017다212095 판결(킹닷컴 v. 아보카도)**: 게임 규칙 하나하나는 아이디어라 보호되지 않지만, 구성요소가 제작 의도·시나리오에 따라 **선택·배열·조합되어 전체적으로 창작적 개성**을 가지면 저작물로 보호되고, 그 조합을 그대로 가져가면 침해 — [법률신문](https://www.lawtimes.co.kr/news/154711) · [ZDNet Korea](https://zdnet.co.kr/view/?no=20190701163736) · [뉴스핌](https://www.newspim.com/news/view/20190701000065) · [리걸타임즈](https://www.legaltimes.co.kr/news/articleView.html?idxno=48090)

따라서 «계단을 오른다·무한·시간 압박»이라는 **아이디어 층위**는 자유롭게 쓰되, 판단 기준은 «통째 복제 여부»가 아니라 **의거성 + 구성요소의 선택·배열·조합에 대한 실질적 유사성**이다. 본작은 (a) 코어 입력(방향 토글 → 정답 선택), (b) 진행 자원(연속 상승 게이지 → 정답·하트), (c) 계단 형태(지그재그 → 분기 발판), (d) 실패 연출, (e) 시각 스타일·캐릭터·제목을 **항목별로** 다르게 설계하고, 남는 공통 조합(세로 무한 상승·시간 압박·하단 입력·기록 경쟁·스킨)은 엔드리스 아케이드 장르의 관용 요소임을 §3-6 비교 문서에서 근거와 함께 적는다. ⚠️ 위 판결 요지 출처는 전부 2차 기사다 — 승인 전 대법원 종합법률정보에서 판결문 원문(2017다212095)의 판단 문단을 확인해 `docs/LEGAL-COMPARE.md` 에 직접 인용한다(사용자·법률 검토 항목).

| 축 | 무한의 계단 | 본작 (차별화 결정) |
|---|---|---|
| 입력 룰 | 2버튼: 오르기 / 방향전환+오르기 | **좌·우(후반 좌·중·우) 갈래 중 «정답 갈래»를 탭** — 방향 토글 개념 없음 |
| 진행 자원 | 시간 게이지(계속 오르면 회복) | **정답만이 한 층을 올림**, 문항별 짧은 타이머 + 하트 3 |
| 계단 형태 | 지그재그 벽돌 계단 | **위로 갈라지는 떠 있는 발판(분기형)**, 갈래마다 답이 적힘 |
| 캐릭터 | 픽셀 사람 캐릭터 | 자체 생성 둥근 카툰 동물/사물 캐릭터(스킨 6) |
| 시각 스타일 | 도트/픽셀 | 플랫 벡터풍 카툰 + 부드러운 그라데이션 |
| 제목·아이콘 | «무한의 계단» | 제목에 «무한»·«계단» 조합 및 «Infinite Stairs» 영문 회피, 아이콘은 문제 카드+발판 모티프 |
| 실패 연출 | 추락 | 발판 금 감·헛디딤 + **정답 발판 하이라이트(교정 피드백)** |

추가 체크리스트:
3-1. **제목 상표**: 후보명 확정 후 KIPRIS(특허정보넷)에서 제41류(교육·오락)·제9류(앱) 선등록 검색 — 사용자 수행 항목. 마케팅 문구·스토어 설명·태그에서 「무한의 계단」을 언급·비교하지 않는다(명칭 비언급은 출처 혼동 위험을 줄일 뿐 없애지는 않는다 — 잔존 위험은 §3-6 에서 관리).
3-2. **부정경쟁방지법 성과물 도용 조항** = 제2조 제1호 **(파)목** «그 밖에 타인의 상당한 투자나 노력으로 만들어진 성과 등을 공정한 상거래 관행이나 경쟁질서에 반하는 방법으로 자신의 영업을 위하여 무단으로 사용함으로써 타인의 경제적 이익을 침해하는 행위»(구 (차)→(카)→(파)목으로 개정 이동, 판단 기준 = 대법원 2020. 3. 26. 선고 2016다276467 판결: 성과의 명성·경제적 가치·고객흡인력, 상당한 투자·노력, 공공영역 여부 종합 — [김·장 해설](https://www.kimchang.com/ko/insights/detail.kc?sch_section=4&idx=21357) · [법률신문 칼럼](https://www.lawtimes.co.kr/news/articleView.html?idxno=196045) · [현행 조문](https://casenote.kr/%EB%B2%95%EB%A0%B9/%EB%B6%80%EC%A0%95%EA%B2%BD%EC%9F%81%EB%B0%A9%EC%A7%80_%EB%B0%8F_%EC%98%81%EC%97%85%EB%B9%84%EB%B0%80%EB%B3%B4%ED%98%B8%EC%97%90_%EA%B4%80%ED%95%9C_%EB%B2%95%EB%A5%A0/%EC%A0%9C2%EC%A1%B0)). 배포 전 국가법령정보센터에서 목 표기 재확인. 룰이 달라도 «전체적 인상»이 같으면 문제될 수 있어 위 표의 표현 축을 전부 다르게 가고, §3-6 비교로 잔존 위험을 문서화한다.
3-3. **에셋**: 이미지 100% 자체 생성(Meta→agy) 또는 CC0(Kenney), 폰트 OFL 자체 호스팅(Pretendard), 사운드 자체 생성(gen-bgm/gen-sfx) — `asset-license.json` 원장 + `free-assets.sh verify` PASS.
3-4. **교육 데이터**: 구구단 = 수학적 사실(보호 대상 아님). 영단어 = 교육부 고시 초등 권장 어휘 범위에서 **단어만** 취하고 뜻·예문·오답은 자작(교과서·시판 단어장 예문 복제 금지).
3-5. **아동 개인정보**: 수집 0(스킬 절대규칙). 광고·분석 SDK 없음. v1 온라인 랭킹 없음.
3-6. **전체적 인상 비교(승인 전 산출물 `docs/LEGAL-COMPARE.md`, GDD D26)**: 두 게임의 **시간순 플레이 흐름**(앱 실행→첫 입력→실패→재시작)과 **화면 구성**(HUD 위치·입력 영역·캐릭터 비중·색·폰트)을 나란히 표로 비교하고, 항목마다 «다름 / 장르 관용 / 동일» 을 판정한다. «동일» 판정 항목이 하나라도 남으면 GDD 를 고친다. 잔존 위험(세로 무한 상승·시간 압박·하단 입력·기록 경쟁·스킨 수집)은 «장르 관용» 근거(다른 엔드리스 게임 5종 이상에서 공통 확인)를 붙인다. 이 문서는 사용자 확인 + 배포 전 변호사/변리사 검토 1회를 거친다.
