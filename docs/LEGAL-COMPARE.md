# 전체적 인상 비교 — 오르답 ↔ 무한의 계단 (D26)

목적: 저작권 판단은 «규칙 하나»가 아니라 **구성요소의 선택·배열·조합이 만드는 전체적 인상**으로
이뤄진다(대법원 2019. 6. 27. 선고 2017다212095). 그래서 항목마다 «다름 / 장르 관용 / 동일» 을 판정한다.

⚠️ 오른쪽 열(무한의 계단)은 **공개된 설명에 근거한 것**이며 제작진이 원작을 해부해 옮긴 것이 아니다.
   판결문 원문 확인과 변호사·변리사 검토는 배포 전 사용자 확인 항목으로 남아 있다(RESEARCH §3-6).

## 1. 시간순 플레이 흐름
| 단계 | 무한의 계단 | 오르답 | 판정 |
|---|---|---|---|
| 앱 실행 후 첫 화면 | 곧바로 플레이 시작 화면 | 과목 카드 3장(구구단·영단어 3·4학년·5·6학년) 중 고르기 | 다름 |
| 시작까지 입력 | 즉시 | 3탭(과목 → 범위 → 시작) | 다름 |
| 한 번의 조작이 하는 일 | 오르기 / 방향전환+오르기 | **문제를 읽고 정답 갈래를 고르기** | 다름 |
| 실패 조건 | 시간 게이지 소진·잘못된 방향 | 오답·시간초과로 하트 3 소진 | 다름 |
| 실패 직후 화면 | 추락 후 결과 | 정답 발판 0.8초 강조 + 정답 안내(교정 피드백) → 결과 | 다름 |
| 재시작 | 즉시 재시작 | 결과 화면에서 «한 판 더»(놓친 문제 1개를 보여 주고 다음 판 예고) | 장르 관용 |

## 2. 화면 구성
| 요소 | 무한의 계단 | 오르답 | 판정 |
|---|---|---|---|
| 진행 방향 | 위로 무한 상승 | 위로 무한 상승 | **장르 관용**(Doodle Jump·Crossy Road 계열 공통) |
| 계단 형태 | 지그재그로 이어진 벽돌 계단 | 좌·우(후반 좌·중·우)로 **갈라지는 떠 있는 발판** | 다름 |
| 발판 위 정보 | 없음 | **선택지 숫자·낱말이 적힌 명판** | 다름 |
| 입력 영역 | 하단 좌우 2버튼 | 발판 위 선택지 버튼(2~3개) | 다름 |
| 시간 표시 | 하단 게이지 바 | 상단 문제 카드 아래 타이머 바 | 다름 |
| 목숨 표시 | 없음 | 좌상단 하트 3 | 다름 |
| 캐릭터 | 픽셀 도트 사람 | 플랫 벡터 카툰 동물 7종(자체 생성) | 다름 |
| 배경 | 단색·패턴 계단 배경 | 구름 바다 위 하늘 4테마(새벽·낮·노을·별밤) | 다름 |
| 색·폰트 | 도트 폰트, 원색 | 시스템 산세리프, 남색 패널 + 노랑 포인트 | 다름 |
| 점수 표시 | 오른 계단 수 | 오른 층수 + 정답률 | 장르 관용 |

## 3. 잔존 공통 요소와 그 근거
| 공통 요소 | 왜 남는가 | 장르 관용 근거(다른 게임에서도 공통) |
|---|---|---|
| 세로 무한 상승 | 「끝없이 오른다」는 아이디어 층위 | Doodle Jump, Icy Tower, Stack Jump, Crossy Road(방향만 다름), NS-SHAFT(하강) |
| 시간 압박 | 즉답 학습의 핵심 장치 | Kahoot, Quizlet Match, 뿌요류 타이머 퍼즐 |
| 하단 입력 | 모바일 세로 화면의 엄지 영역 | 거의 모든 세로 캐주얼 게임 |
| 기록 경쟁 | 엔드리스 장르의 정의적 요소 | Flappy Bird, Crossy Road, Doodle Jump |
| 스킨 수집 | 코스메틱 메타의 표준형 | Crossy Road, 쿠키런 |

«동일» 판정 항목: **0건**.

## 5. 부정경쟁방지법 제2조 제1호 (파)목 관점
성과 도용 판단은 ① 성과의 명성·경제적 가치·고객흡인력 ② 상당한 투자·노력 ③ 공정한 상거래 관행 위반
여부를 종합한다(대법원 2020. 3. 26. 선고 2016다276467).
본작은 원작의 **규칙 조합도 표현도 가져오지 않았고**, 에셋·데이터·코드를 전부 자체 제작했다.
남은 공통 요소는 위 §3 대로 장르 관용에 해당한다.
