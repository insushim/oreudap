# 개인정보 처리 — 오르답

한 줄 요약: **아무것도 수집하지 않습니다.** 수집하지 않은 정보는 유출될 수 없습니다.

## 받지 않는 것
실명·별명 입력 · 나이·생년월일 · 학교·학년·반 · 이메일·전화번호 · 사진·음성 ·
자유 텍스트(채팅·댓글) · 계정·회원가입·로그인 · 광고 SDK · 분석 SDK · 위치 · 연락처.
게임 화면에 **입력 필드가 하나도 없습니다**(게이트 D21 이 0개를 단언합니다).

## 기기에 저장하는 것 (브라우저 localStorage, 키 `oreudap:progress`)
코인 수 · 해금한 캐릭터·하늘 · 과목별 최고 층 · 오답노트 박스 진행도 ·
오늘의 미션 진행 · 소리·흔들림·색약 설정.
이 값들은 **이 기기의 브라우저 안에만** 있습니다. 서버로 보내지 않고, 저희도 볼 수 없습니다.
브라우저의 「사이트 데이터 삭제」로 언제든 전부 지울 수 있습니다.

## 네트워크
게임에 필요한 파일(HTML·자바스크립트·그림·소리)을 **같은 도메인에서 GET 으로만** 받습니다.
외부 폰트·CDN·분석 서버로 나가는 요청이 0건입니다 — 아이의 IP 주소가 제3자에게 가지 않도록
글꼴은 기기에 이미 있는 시스템 글꼴만 쓰고, 라이브러리는 자체 호스팅합니다.
게이트 D21 이 배포 전마다 전수 확인합니다(외부 요청 0 · POST 0 · 쿼리스트링 0 · 요청 본문 0).

## 서버 로그
정적 호스팅이라 접속 로그는 호스팅 제공자의 기본 웹서버 로그(IP·시각·요청 경로)뿐이며,
저희가 별도로 수집·보관·분석하지 않습니다.

## 아이를 위한 설계 원칙
- 랭킹을 넣더라도 자유 입력 이름은 쓰지 않습니다(생성 닉네임만).
- 오답이 «벌»이 되지 않게 만듭니다. 못하는 아이가 더 나빠지는 장치를 두지 않습니다.
- 학습 기록은 기기 안에서 보여 주기만 합니다. 이메일 발송·서버 전송이 없습니다.

## 문의
이 문서와 실제 동작이 다르다고 느끼면 알려 주세요. 게이트 로그(`qa/`)로 확인해 드립니다.
