2. 오르답에 특히 잘 맞는 것만 추리면

오르답 조건이 구구단/영단어 + 계단 오르기 + 로그인 없음 + 개인정보 0 + 1~3분이라면 서버 계정 기반 장기 메타를 흉내낼 필요가 없다. 오히려 다음 6개 층이면 충분해 보인다.

A. 1판 안의 목표 — 「이번엔 42층 넘는다」

Infinite Stairs/Doodle Jump 방식이다.

게임 오버 화면에 단순히

최고 47층 / 이번 43층

이라고 하는 것보다,

최고 47층 — 4층 남음!

처럼 다음 목표와 거리를 보여주는 편이 낫다.

재시작 버튼은 즉시 눌리게 하고 로딩이나 메뉴 복귀를 없앤다.

B. 학습 콤보 — 「7단 PERFECT × 4」

Kahoot/Quizizz의 즉각 피드백을 계단 액션에 결합한다.

예를 들어:

정답 ×3 → 계단 불꽃
정답 ×5 → FEVER
정답 ×10 → 보너스 계단
한 판 전부 정답 → PERFECT 도장

여기서 중요한 건 랜덤하게 능력을 주는 게 아니라 학습 성공이 게임 능력으로 변하는 것이다.

C. 작은 도감 — 「계단 스킨 30개」

Infinite Stairs + Monkey Junior가 좋은 참고다. Infinite Stairs는 현재 1,000종 이상의 수집 콘텐츠와 주기적 보상 업데이트를 전면에 내세우고 있다.

기본 계단

가챠는 필요 없다. 아이가 “앞으로 무엇을 얻는지” 볼 수 있게 하는 편이 교육용 게임에는 더 깔끔하다.

E. 일일 스트릭 대신 「이번 주 도장」

여기서는 Duolingo를 그대로 따라 하지 않는 것이 중요하다.

Khan Academy가 현재 사용하는 주간 streak처럼 더 느슨하게 만들 수 있다. Khan Academy는 일주일에 최소 하나의 새 skill을 Proficient로 만들면 streak가 이어진다.

F. 「거의 달성했다」를 게임오버 화면에 보여주기

이건 Doodle Jump식 최고점 추구와 Khan Academy식 progress visualization을 섞기 좋다.

예:

63층!

🏆 최고 기록 68층
최고 기록까지 5층

7단 정확도 ████████░░ 82%

🚀 우주 계단까지 별 7개

[바로 다시!]

이 화면에는 동시에 3개의 미완성 목표가 있다.

5층만 더

별 7개만 더

따라서 굳이 “내일 접속하세요”라고 압박하지 않아도 한 판 더의 이유가 생긴다.

4. 초등학생 대상이라면 피할 강박 장치

OECD는 dark commercial pattern을 사용자의 선택을 조종·기만·강제해 자신의 이익에 반하는 결정을 하게 만드는 인터페이스 관행으로 설명하며, 아동은 이런 관행에 불균형하게 영향을 받을 수 있다고 지적한다. 특히 아동 앱 연구를 정리한 OECD 자료에서는 조사 앱 다수에서 가짜 시간 압박, 매력적 유인물, 탐색 제한, 더 오래 플레이하거나 구매하도록 하는 압박 등이 발견됐다.

2. 교육심리 근거: 내적 동기 보호와 외적 보상의 함정
1) 내적 동기를 해치지 않으면서 지속성을 만드는 조건

초등 저·중학년(만 7~10세)은 근면성 대 열등감이 형성되는 에릭슨 발달단계에 위치하여, "내가 스스로 해냈다"는 감각이 학습 지속성의 핵심이 됩니다.

자기결정이론(Self-Determination Theory, Deci & Ryan):

유능성(Competence): 문제가 너무 쉽거나 좌절스러울 정도로 어렵지 않고, 현재 실력보다 아주 살짝 높은 도전 과제(비고츠키의 '근접발달영역')를 스스로 해결했을 때 도파민과 성취감이 강화됩니다.

자율성(Autonomy): 캐릭터 외형 변경, 풀고 싶은 단원이나 맵의 순서를 직접 선택하게 하는 등 통제권을 아이에게 쥐여줄 때 지속성이 극대화됩니다.

관계성(Relatedness): 혼자 고립되어 점수를 쌓기보다, 가상 NPC(동물 친구)를 구출하거나 학급 친구들과 함께 협동 미션을 달성하는 경험이 안정감을 줍니다.

숙달목표(Mastery Goals) 지향:

다른 아이와의 서열(수행목표)이 아닌, "어제의 나보다 오늘 더 빨라졌다", "틀렸던 문제를 스스로 고쳐냈다"는 개인적 성취와 숙달 자체에 초점을 맞추는 피드백(프로세스 칭찬)을 설계해야 포기하지 않습니다.

2) 외적 보상이 내적 동기를 깎아먹는 조건: 과잉정당화 효과 (Overjustification Effect)

과잉정당화 효과는 원래 아이가 순수하게 재미있어서 하던 활동에 금전이나 사탕 같은 '통제적 외적 보상'을 제공하면, "내가 재미있어서 하는 게 아니라 보상을 받으려고 억지로 한다"고 인과관계를 재귀인하면서 본래의 호기심이 사라지는 현상입니다.

동기를 파괴하는 보상 (통제적 보상):

수행 연계형 보상(Task-contingent): "이거 10분 풀면 젤리 줄게", "문제 다 맞히면 콘(포인트) 줄게"와 같이 행동의 조건을 통제 수단으로 사용할 때 내적 동기가 가장 빠르게 하락합니다.

보상이 끊기면(체험 기간 종료, 부모의 보상 중단 등) 그 즉시 해당 학습 활동 자체를 완전히 거부하게 됩니다.

동기를 보호하는 보상 (정보적 피드백):

사전에 약속된 거래형 보상이 아니라, 아이가 과제를 잘 끝마쳤을 때 나오는 예상치 못한 보너스 축하(Unexpected reward)나 등급이 아닌 기능적 언락(새로운 게임 연출 잠금 해제, 새로운 배경 테마 획득) 형태의 '정보적 피드백'은 내적 동기를 훼손하지 않습니다.

## 3. 결론 — 오르답에 넣은 것과 넣지 않은 것

### 넣는다
| 순위 | 장치 | 상태 |
|---|---|---|
| 1 | 개인 최고 + 남은 거리 | 이미 있음 (강화) |
| 2 | 즉시 재도전 | 이미 있음 |
| 3 | 학습 콤보(스트릭) | 이미 있음 |
| 4 | **도감(깃발·구간)** | 신규 — 여정 |
| 5 | 일일 미션 3종 | 이미 있음 |
| 6 | **오늘의 계단(날짜 시드)** | 신규 |
| 7 | **숙련도 게이지** | 신규 |
| 8 | **느슨한 주간 도장** | 신규 |

### 넣지 않는다 (게이트 D39 가 기계로 막는다)
두 조사가 **공통으로** 지목했고, OECD 아동 다크패턴 보고가 근거다.

| 금지 | 왜 |
|---|---|
| 깨지면 0이 되는 연속 출석 | 저학년에게 좌절·앱 삭제를 유발. 손실회피를 아이의 핵심 동기로 쓰지 않는다 |
| FOMO 카운트다운 | OECD 가 아동 앱에서 지목한 fabricated time pressure |
| 가챠·랜덤박스·희귀도 | 아동은 확률·화폐 관계를 충분히 이해하지 못한다 |
| 실패 직후 부활 유도 | 감정적으로 취약한 순간을 이용한다 |
| 에너지 고갈 → 대기 | 학습 자체가 벌이 된다 (오르답 원칙 「오답이 벌이 되지 않게」와 정면 충돌) |
| 끝없는 보상 사슬 | 자연스러운 종료점을 없앤다 → **그래서 「오늘 할 만큼 했어요」를 화면이 먼저 말한다(D40)** |

### 보상 형태의 원칙 (과잉정당화 효과)
「이거 풀면 코인 줄게」식 **수행 연계 보상**은 내적 동기를 가장 빨리 깎는다.
그래서 신규 해금(구간·깃발·황금 계단)의 보상은 **코인이 아니라 기능적 언락**이다 —
조사가 「정보적 피드백」이라 부른 형태. 기존 코인·상점은 그대로 두되 축을 분리한다.
